╔══════════════════════════════════╗
║         VIM  CHEATSHEET          ║
╚══════════════════════════════════╝

── THIS PANE ───────────────────────
  <CR>/tab  open / close a section
  J / K     next / prev section
  f         filter (F clears it)
  zR / zM   expand / collapse all
  q / ESC   close the pane
  :Cheatsheet <text>  open filtered

── MODES ───────────────────────────
  i         insert before cursor
  a         insert after cursor
  o / O     new line below / above
  v         visual (char)
  V         visual (line)
  ctrl+v    visual (block)
  ESC       back to normal mode

── MOTION ──────────────────────────
  gg / G    top / bottom of file
  H/M/L     top/middle/bottom screen
  w / b     next / prev word
  0 / $     start / end of line
  %         jump to matching bracket
  *         search word under cursor
  '.        jump to last edit
  ctrl+o    jump back in history
  ctrl+i    jump forward in history

── EDITING ─────────────────────────
  ciw       change inner word
  ci"       change inside quotes
  di"       delete inside quotes
  yiw       yank inner word
  p / P     paste below / above
  u         undo
  ctrl+r    redo
  .         repeat last change
  ~         toggle case
  >>  /  << indent / dedent line
  gcc       comment line (if plugin)

── SEARCH & REPLACE ────────────────
  /foo      search forward
  ?foo      search backward
  n / N     next / prev result
  :%s/a/b/g replace all in file
  :s/a/b/g  replace all in line
  :g/pat/d  delete lines matching

── VISUAL MODE ─────────────────────
  ctrl+v    column/block select
  ctrl+q    same (if terminal eats ^V)
  <space>v  same (always works)
  I / A     insert / append on block
  c         change block
  r<char>   fill block with char
  gv        reselect last selection
  >  /  <   indent / dedent selection

── MULTI-CURSOR (live) ─────────────
  ctrl+n    select word, again = next
  ctrl+down add cursor below
  ctrl+up   add cursor above
  <space>m  select ALL occurrences
  tab       cursor <-> extend mode
  n / N     next / skip occurrence
  q         skip this one, go to next
  ESC       back to one cursor
  (edits show live, no ESC needed)

── DIFF (side by side) ─────────────
  <space>d  diff this file vs HEAD
  :GitDiff <rev>  vs any revision
  ]c / [c   next / prev change
  do        take their version (get)
  dp        push mine over (put)
  :diffupdate  recompute
  <space>d  close the diff
  shell: gdv = gdf side by side
         gsv <sha> = gs side by side
    :qa   next file   :cq  abort run

── LESS (the pager) ────────────────
  j / k     line down / up
  ctrl+f/b  page fwd / back
  ctrl+d/u  half page
  gg / G    top / bottom
  / ?  n N  search fwd/back, next/prev
  <space>h  clear search highlight
  &pat      show ONLY matching lines
  m<a> '<a> set / jump to mark
  v         edit this file in vim
  F         follow, like tail -f
  -S        toggle line wrapping
  q / ZZ    quit
  h         less's own help

── SPLITS & WINDOWS ────────────────
  ctrl+w s  horizontal split
  ctrl+w v  vertical split
  ctrl+w h/j/k/l  navigate splits
  ctrl+w =  equalise split sizes
  ctrl+w q  close split

── BUFFERS ─────────────────────────
  :b <tab>  cycle buffers
  :bn / :bp next / prev buffer
  :bd       close buffer

── FILES ───────────────────────────
  :e file   open file
  :w        save
  :q        quit
  :wq       save and quit
  :q!       quit without saving

── COMMAND LINE ────────────────────
  :sort     sort selected lines
  :earlier 5m  rewind file 5 mins
  ctrl+r "  paste last yank in cmdline

── LEADER MAPPINGS (space) ─────────
  <space>w  save file
  <space>q  quit
  <space>h  clear search highlight
  <space>v  block (visual) select
  <space>c  toggle cheatsheet
  F1        toggle cheatsheet
  q / ESC   close it (from inside)

── MARKS ───────────────────────────
  ma        set mark a
  `a        jump to mark a
  ''        jump to last jump point

── MACROS ──────────────────────────
  qa        record macro into a
  q         stop recording
  @a        play macro a
  @@        replay last macro
